NexusGameWiki

Guild Wars 2 in-game wiki viewer for Nexus, with live search, rich article rendering, contents navigation, favorites, recent pages, and disk-first caching.

Download Latest Release View Source

Features

  • Search the Guild Wars 2 wiki without alt-tabbing.
  • Render articles with sections, tables, infoboxes, links, and images.
  • Use a right-side contents panel to jump through long pages.
  • Keep recent pages and favorites in the left pane.
  • Cache searches, pages, and images locally for faster reopen.

Install

  • Install Nexus for Guild Wars 2.
  • Put NexusGameWiki.dll inside Guild Wars 2\addons\.
  • Put the NexusGameWiki\ folder beside it in Guild Wars 2\addons\.
